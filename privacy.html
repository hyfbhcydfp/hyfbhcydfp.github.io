Privacy Policy

Application: Rclone Personal Transfer
Last updated: October 29, 2026

Scope of use

This is a privately configured OAuth application for the owner's use with rclone and their Google Drive account. It is not offered as a public file-transfer service.

Google user data accessed

With the owner's consent, rclone may access Google Drive file and folder names, metadata, and file contents. Depending on the commands the owner chooses, rclone may list, download, upload, modify, move, or delete files.

How data is used and stored

Data is used only to perform file-management operations initiated by the owner. File contents are transferred between the owner's authorized local or selected storage locations and Google Drive. Rclone stores OAuth credentials in its local configuration so it can carry out authorized requests. Temporary memory or local disk caching may occur depending on the selected rclone operation and settings.

Disclosure and sharing

Google Drive user data is not sold, used for advertising, or intentionally disclosed to unrelated third parties. Data is transmitted to Google APIs to carry out the owner's requested operations. No separate application-operated server receives the owner's Google Drive files or OAuth tokens.

This website

This static informational website does not request access to Google accounts and does not intentionally run tracking scripts or collect form submissions. GitHub Pages hosts the website and may process ordinary site access information under GitHub's privacy statement.

Control and revocation

The owner controls the local rclone configuration and can revoke Google account access in their Google Account security settings. Removing the local OAuth credentials also stops that local configuration from making authenticated requests.

Changes

This policy will be updated if the application's behavior or data practices materially change.
