Rclone Personal Transfer

A personal Google Drive connection for file transfer and backup using rclone, a third-party command-line file management tool.

Purpose

This OAuth application is configured for the account owner's private use. It allows the owner to authorize rclone on their own Windows computer to list, upload, download, and manage files in their Google Drive account when they explicitly request these operations.

Google account access

The application requests Google Drive file access for the above functions. File operations are initiated locally through rclone. This static website is informational only: it does not provide login functionality, receive Google Drive files, or process OAuth tokens.
